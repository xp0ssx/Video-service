## Готовые интерфейсы и схема

| Интерфейс | Поведение |
| --- | --- |
| `/` | Карточки public/ready/visible видео, превью, автор, длительность, подгрузка |
| `/results?q=` | Поиск по подстроке без учёта регистра, loading/empty/error/retry |
| `/watch/:id` | Плеер, лайк/снятие, комментарии с пагинацией и формой для сессии |
| `GET /api/videos?q=&cursor=&limit=` | Публичная выдача, keyset `(published_at DESC, id DESC)` |
| `GET /api/videos/{id}` | Метаданные просмотра с `likes_count` и `liked_by_me` |
| `PUT/DELETE /api/videos/{id}/like` | Идемпотентное изменение своего лайка |
| `GET/POST /api/videos/{id}/comments` | Чтение с keyset `(created_at ASC, id ASC)`, добавление текста |

Поиск проверен для кириллицы, буквальных `%`, `_`, `!` и обратного слеша.
Доступ к взаимодействиям проверяется через `can_watch`, изменения требуют
Origin, сессию и CSRF. Роли moderator/admin не обходят приватность.

Миграция `694349d098b8` следует за `c970a1085bb1`, добавляет только `likes` и
`comments`: составной PK лайка, FK, CHECK текста и индекс комментариев.
Рабочая БД находится на этой head-ревизии; `alembic check` на тестовой БД не
обнаружил расхождений с metadata. Существующий видеоконвейер не меняется.

## Исправление по независимому ревью: F13

Независимое ревью выявило один блокирующий дефект F13: запрос из 200 букв `w`
на `/results?q=` увеличивал `scrollWidth` до 5504 px при viewport 1440 px.
Предыдущая визуальная проверка не покрывала этот граничный запрос; остальные
функции по результатам независимого ревью работают.

Дефект воспроизведён новым постоянным тестом `tests/e2e/search_layout.cjs` до
исправления. Минимальная CSS-правка в `global.css` задаёт `min-width:0` для
flex-элемента с заголовком ленты и `overflow-wrap:anywhere` для его `h1` на
всех ширинах. Заголовок полностью читается с переносами, глобальное
`overflow-x:hidden` не добавлено. `HomePage.tsx` и backend не изменялись.

После исправления Chromium-тест прошёл для 200 `w` и короткого запроса,
отправляемого через форму поиска:

| Viewport | scrollWidth для длинного / короткого запроса | Перекрытия |
| --- | --- | --- |
| 1440 px | 1440 / 1440 px | Не обнаружены |
| 390 px | 390 / 390 px | Не обнаружены |

Тест использует production SPA и синтетические HTTP-ответы, проверяет полноту
текста заголовка, границы контейнера, сетку из трёх карточек, боковую навигацию,
поиск, бренд и аккаунт с username из 32 символов. Ошибок console/pageerror нет.
Скриншоты длинного запроса на обеих ширинах просмотрены: текст переносится,
карточки и навигация сохраняют раскладку. Рабочие данные тест не изменяет.

Повторно прошли `feed_state.cjs` (включая мобильную шапку и взаимодействия),
`auth_state.cjs`, TypeScript typecheck и production build через
`docker compose --profile checks run --build --rm frontend-checks`.
`git diff --check HEAD` и проверка Git-кандидатов на локальные credentials,
